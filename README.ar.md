# Ticket Bot Lite

بوت تكتات خفيف وسريع مسوّى لسيرفر **واحد**. ما يحتاج قاعدة بيانات، كل شي ينحفظ بملف JSON واحد جنب البوت.

[English](README.md)

## شنو يسوي

- لوحة تكتات بقائمة أقسام (لين 25 قسم، وكل قسم له رتبة إدارة خاصة)
- أزرار استلام وإغلاق وإعادة فتح وحذف داخل كل تذكرة
- سجل HTML للتذكرة ينرسل لقناة السجلات ولصاحب التذكرة وقت الحذف
- حد أقصى للتذاكر المفتوحة لكل عضو، كولداون بسيط، وبلاك ليست
- `/add` و `/remove` للتحكم بمن يشوف التذكرة
- واجهة عربي وإنجليزي
- يشتغل بأقل موارد: مكتبتين فقط وبدون أي مكتبات native

## المتطلبات

- Node.js 18 أو أحدث
- توكن بوت ديسكورد

## التركيب

1. سوّي تطبيق من [Discord Developer Portal](https://discord.com/developers/applications) وأضف له بوت وانسخ التوكن.
2. من صفحة **Bot** فعّل **Message Content Intent** إذا تبي السجل يحتوي نص الرسائل. البوت يشتغل حتى بدونه، بس السجل يطلع بدون نص.
3. ادعو البوت بهذا الرابط (بدّل `YOUR_CLIENT_ID`):

   ```
   https://discord.com/oauth2/authorize?client_id=YOUR_CLIENT_ID&scope=bot%20applications.commands&permissions=268553232
   ```

   الصلاحيات اللي بالرابط: Manage Channels و Manage Roles و View Channels و Send Messages و Embed Links و Attach Files و Read Message History.
4. حمّل المشروع وثبّت المكتبات:

   ```
   git clone <رابط الريبو>
   cd ticket-bot-lite
   npm install
   ```

5. انسخ `.env.example` إلى `.env` وعبّيه:

   ```
   TOKEN=توكن البوت
   GUILD_ID=آيدي السيرفر
   LANGUAGE=ar
   TRANSCRIPTS=true
   ```

   فعّل Developer Mode من ديسكورد، كلك يمين على السيرفر واختار Copy Server ID عشان تجيب `GUILD_ID`. استخدم `LANGUAGE=en` للإنجليزي.
6. شغّله:

   ```
   npm start
   ```

أوامر السلاش تتسجل بسيرفرك تلقائي كل ما يشتغل البوت.

## أول خطوات داخل ديسكورد

1. `/section add` - سوّي قسم وحدد رتبة الإدارة له. أضف كم قسم تبي.
2. `/config` - اختار الكاتيجوري للتذاكر وقناة السجلات. إذا شغلته بدون خيارات يعرض لك القيم الحالية.
3. `/setup` - اكتبه بالقناة اللي تبي اللوحة تنزل فيها.

## الأوامر

| الأمر | لمن | شنو يسوي |
| --- | --- | --- |
| `/setup` | Manage Server | يرسل لوحة التذاكر بالقناة الحالية |
| `/section add / remove / list` | Manage Server | إدارة الأقسام |
| `/config` | Manage Server | الكاتيجوري وقناة السجلات وأقصى عدد تذاكر للعضو |
| `/blacklist add / remove / list` | Manage Server | منع أعضاء من فتح التذاكر |
| `/add` `/remove` | الإدارة | إضافة أو إزالة عضو من التذكرة الحالية |
| `/help` | الكل | شرح مختصر للإعداد |

## وين تنحفظ البيانات

كل شي بالملف `data/data.json`. عشان تاخذ نسخة احتياطية أو تنقل البوت لجهاز ثاني انسخ هذا الملف. وإذا الملف تخرب لأي سبب البوت يغيّر اسمه إلى `data.json.broken-<الوقت>` ويبدأ بملف جديد بدل ما يتوقف.

## ملاحظات

- حالة البوت تكون "Playing discord.gg/ownr". تقدر تغيرها من `config.js`.
- الكولداون والحد الافتراضي للتذاكر موجودين بـ `config.js` بعد.
- البوت مسوّى لسيرفر واحد. الأوامر والأزرار تتجاهل أي سيرفر ثاني.
